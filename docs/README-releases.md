# Arcadia — lanceur de jeux PC

Arcadia rassemble tous vos jeux PC (Steam, Epic, GOG, Ubisoft, Xbox, émulateurs, raccourcis…) dans une seule bibliothèque, avec leurs jaquettes, votre temps de jeu, un mode TV pour la manette et des thèmes d'interface dans l'esprit des menus de consoles.

Ce dépôt ne contient que les versions publiées.

## Installer

1. Ouvrez **[la dernière version](../../releases/latest)** et téléchargez **`Arcadia.exe`**.
2. Lancez-le. Aucune installation de .NET ni d'autre logiciel n'est nécessaire.
3. Windows peut afficher « Windows a protégé votre ordinateur » : l'application n'est pas signée par un éditeur payant. Cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.
4. Facultatif : *Réglages → Système → Installer* copie Arcadia dans vos programmes et crée un raccourci dans le menu Démarrer.

Premier lancement : **Ajouter des jeux → Détecter les jeux installés**, ou glissez vos raccourcis de jeux dans la fenêtre.

## Mises à jour

Arcadia vérifie au démarrage s'il existe une nouvelle version et propose de l'installer en un clic. Votre bibliothèque et vos réglages sont conservés. Vous pouvez aussi vérifier à la main dans *Réglages → Mises à jour*.

## Vos données

Tout reste sur votre PC, dans `%APPDATA%\Arcadia`. Arcadia ne modifie, ne déplace et ne supprime jamais les fichiers de vos jeux.
